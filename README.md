# At the Moment

A cozy multi-topic personal blog — books, film, series, tech, esports, and whatever else lands on the shelf.

**Live:** https://sheil4tm.github.io/

## Stack

- Astro + Content Collections
- Tailwind CSS
- Pagefind (full-text search)
- GitHub Pages

## Local development

```bash
npm install
npm run dev
```

Then open http://localhost:4321.
